## 📖 Descripción
FórumHub es una API RESTful desarrollada como parte de los desafíos del programa Oracle Next Education (ONE) en colaboración con Alura Latam. Este proyecto simula el backend de un foro de discusiones, permitiendo a los usuarios autenticados crear, visualizar, actualizar y eliminar tópicos.

## 🚀 Tecnologías Utilizadas
* **Java 21**
* **Spring Boot 3**
* **Spring Security** (Autenticación y Autorización)
* **Token JWT** (Librería Auth0)
* **Spring Data JPA & Hibernate**
* **Flyway** (Migraciones de Base de Datos)
* **Springdoc OpenAPI / Swagger** (Documentación interactiva)

## ✨ Funcionalidades
1. **Autenticación:** Sistema de login que genera un Token JWT (JSON Web Token) con un ciclo de vida definido (2 horas) para asegurar las rutas.
2. **Gestión de Tópicos (CRUD):** * Crear nuevos tópicos.
   * Listar todos los tópicos.
   * Buscar un tópico específico por su ID.
   * Actualizar la información de un tópico.
   * Eliminar tópicos.
3. **Documentación Interactiva:** Interfaz gráfica autogenerada para probar todos los endpoints sin necesidad de clientes externos.
